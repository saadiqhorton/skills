# Production Python Code

Write Python that is ready for production: cohesive, encapsulated, loosely
coupled, extensible, portable, defensive, testable, and simple. This skill is
the agent-facing wrapper for the teaching repo in `examples/` — every principle
has a runnable **bad → good** pair you can inspect, run, and use as a refactor
target.

## Install

```bash
# Project-local (default) → ./<agent>/skills/
npx skills add saadiqhorton/skills@production-python-code

# Global → ~/<agent>/skills/
npx skills add saadiqhorton/skills@production-python-code -g
```

## Contents

- `SKILL.md` — entry point: the eight principles, workflows (write, review,
  refactor), Python-specific best practices, and verification commands
- `examples/` — complete teaching repo: `QUICK_REFERENCE.md` plus 8 module
  dirs, each with a README and runnable bad → good code
- `references/` — deep-dive docs: design principles, code smells & fixes,
  Python specifics, and verified sources
